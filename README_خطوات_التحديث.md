# تحديث وصّلي (نسخة 1.0.0+6)

## 1) فك الملفات
فُك الـ zip فوق مجلد المشروع (بيستبدل الملفات بنفس المسارات).

## 2) امسح الملفين دول (اتشالوا من المشروع)
- lib/services/first_order_service.dart
- lib/widgets/free_delivery_sheet.dart

## 3) فحص وتشغيل
    flutter pub get
    flutter analyze
    flutter run            (على موبايل حقيقي)

لو flutter analyze طلّع أي خطأ (error) ابعتهولي.

## 4) نشر القواعد والفهارس
    firebase deploy --only firestore:rules,firestore:indexes

## 5) بعد النشر
- الطلبات اللي كانت «جاري التحضير» قبل التحديث لازم المحل (أو الأدمن) يضغط عليها «الطلب جاهز للاستلام» عشان المندوب يقدر يبدأ التوصيل.
- (اختياري، مش لازم دلوقتي) لتفعيل الحماية في القواعد كمان: أضف حقل courierAfterReady = true (boolean) في المستند app_info/security.
- لو رفعت نسخة 1.0.0+6 قبل كده على Play، زوّد رقم البناء في pubspec.yaml (مثلًا +7).

## اللي اتغيّر
1. توصيل مجاني لأول طلب: اتلغى بالكامل (النافذة والشريط والحساب وسطر سياسة الخصوصية). القاعدة القديمة first_orders فضلت في الـ rules عشان النسخ القديمة ما تفشلش.
2. رفع الصور من المعرض: متوقف (kImageUploadEnabled = false في image_service.dart). بدله نافذة لصق رابط صورة https. لما تعمل Blaze غيّرها لـ true.
3. خطوة «الطلب جاهز للاستلام»: زرار عند صاحب المحل وعند الأدمن، والمندوب مش بيشوف زرار الاستلام إلا بعدها. العميل بيجيله إشعار داخل التطبيق.
4. تنبيهات لحظية (شريط + صوت): صاحب المحل بطلب جديد، المندوب بطلب متاح وبجاهزية طلبه.
5. الصوت: ملف assets/sounds/bell.wav متضمّن + قسم assets في pubspec.
6. القواعد: دمج match /app_info المكرر في واحدة (نفس الصلاحيات) + صلاحية «جاهز» + مفتاح courierAfterReady.
